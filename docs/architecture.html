System Architecture · Client Onboarding

One form, one trusted messenger, one source of truth.

How a new agency client goes from added in GHL to fully onboarded — without a back-and-forth thread, without re-typing details, without you opening the CRM until it's time to start their buildout.

The four pieces
The Form
onboarding.youragency.com
  • Pre-fills name + company from GHL when client clicks a personalized link
  • Shows a small intake card if they arrived without a link (walk-up)
  • Collects 25 business fields in 5–10 minutes
What the client sees
HTTPS
The Worker
leads-proxy · cloudflare
  • Sits between the public form and your GHL account
  • Holds the GHL access keys so the form never has to
  • Handles 3 routes: load contact, save submission, upsert walk-up
KV store — the Worker's notecard. Holds GHL keys + the form-field-to-GHL-field translation table.
The trusted messenger
API
GoHighLevel
acme sub-account
  • The contact record for every client — name, email, 25 custom fields
  • Tags act as triggers: send-onboarding fires the email; onboarding-complete notifies you
  • Workflows handle every automatic email so you don't have to
The source of truth
The journey — warm-link path
01 Add the tag YOU · in GHL

Drop the send-onboarding tag on a new contact.

02 Email fires GHL · workflow

Personalized link auto-sends with their secret ID baked in.

03 Client clicks CLIENT · browser

Form loads, asks the Worker "what do we already know?"

04 Pre-fill WORKER ↔ GHL

Worker pulls the contact; form fills in everything on file.

05 Submit CLIENT · form

Client fills the rest, hits submit. Worker writes all 25 fields back.

06 You're notified GHL · workflow

onboarding-complete tag fires; you get a summary email.

Walk-up path

If someone arrives at the URL without a personal link (you shared it verbally, a referral forwarded it, they typed it in), the form shows a small name + email card first. The Worker upserts a contact in GHL (tagged cold-intake), returns an ID, and the experience continues identically. If their email matches an existing contact, they get the same pre-filled experience as the warm-link path — no duplicates, no re-typing.
